# 🎯 Multi-Exam Consistency & Study Command Center

A Python-based web application built with **Streamlit** to help aspirants track their daily study hours, manage exam-specific syllabi, log test performance, and monitor screen time.

## 🚀 Supported Exams
- UPSC Civil Services
- CAT
- GATE
- APPSC / TGPSC Groups
- SSC CGL

## ✨ Features
- **Target Exam Switcher:** Dynamically updates syllabus tracking and analytics based on your chosen exam.
- **Daily Progress Logging:** Track study hours, subjects, tests written, and screen time.
- **Screen-Time Alerts:** Built-in warning and success banners to keep distractions in check.
- **Syllabus Tracker:** Interactive expanders and checkboxes to track module completion percentages.
- **Visual Analytics:** Real-time charts and summary metrics for study consistency.

## 🛠️ Tech Stack
- **Python**
- **Streamlit** (UI & Dashboard)
- **Pandas** (Data Management)
